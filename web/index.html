Objectif du projet

Banc d'essai Text-to-Speech (TTS)

Ce projet évalue et compare différents moteurs de synthèse vocale pour le français (fr-FR), en vue d'une intégration dans l'application NextJS (NowWeAct) et d'un déploiement auto-hébergé sur VPS OVH.

Edge TTS API Cloud Microsoft

Voix neurales Microsoft Edge via endpoint gratuit sans clé API. Moteur de référence actuellement en production dans NowWeAct.

Stack technique : edge-tts-universal • Node.js (ESM) • WebSocket
Prérequis & Ressources :
  • Connexion Internet requise (port HTTPS/WSS)
  • Zéro clé API • Empreinte mémoire minime (~15 Mo)
  • Licence lib : AGPL-3.0 • Sortie : MP3 24kHz
Piper 100% Local CPU

Moteur ultra-rapide et léger tournant entièrement en local sur CPU sans GPU ni dépendance réseau.

Stack technique : Binaire C++ natif • child_process • ONNX models
Prérequis & Ressources :
  • 100% Hors-ligne • CPU x86_64 standard (sans GPU)
  • Modèles dans server/voices/ (~60 Mo RAM)
  • Licence : MIT/GPL-3.0 • Sortie : WAV 22.05kHz
Kokoro Local ONNX 82M

Modèle neuronal compact 82M paramètres StyleTTS2 offrant un timbre studio naturel supérieur à Piper.

Stack technique : kokoro-js • onnxruntime-node (q8) • espeak-ng IPA
Prérequis & Ressources :
  • 100% Hors-ligne • CPU moderne (AVX2) ou GPU
  • Binaire server/bin/espeak-ng pour phonèmes fr
  • Licence : Apache 2.0 • Sortie : WAV 24kHz studio
Chatterbox Clonage Vocal Local

Moteur de clonage vocal zéro-shot (Resemble AI) pour synthétiser avec le timbre exact d'un échantillon audio.

Stack technique : FastAPI • PyTorch 2.6 • CUDA 12.4 • chatterbox-tts
Prérequis & Ressources :
  • GPU NVIDIA recommandé (CUDA, ~2-3 Go VRAM)
  • Virtualenv Python server/python/.venv/
  • Licence : MIT commerciale • Sortie : WAV 24kHz

Synthèse des moteurs : Edge TTS pour la simplicité immédiate, Piper pour la légèreté CPU, Kokoro pour le compromis parfait qualité/poids local, et Chatterbox pour la personnalisation vocale.

Guide d'utilisation & Aide rapide
1
Choisir le moteur : Cliquez sur Edge TTS pour le cloud Microsoft, Piper pour le local CPU, Kokoro pour la qualité studio ONNX, ou Chatterbox pour le clonage vocal.
2
Sélectionner une voix : Cliquez sur l'un des profils de voix disponibles (féminine, masculine, référence audio).
3
Ajuster les paramètres : Réglez la vitesse, la cadence ou l'exagération émotionnelle selon le moteur.
4
Générer & Comparer : Cliquez sur Générer la voix. L'audio se lance directement avec son temps de calcul affiché.
5
Historique & Favoris : Marquez avec le bouton vos rendus favoris, copiez le chemin du fichier ou réutilisez le texte en 1 clic.
